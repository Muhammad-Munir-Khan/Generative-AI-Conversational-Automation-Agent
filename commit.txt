fix: repair summarizer crash and ensemble empty-verdict bug

Two runtime bugs found during multilingual testing.

ensemble: judge returned "(no verdict)" for some languages (e.g. Japanese)
because the language directive made it translate JSON keys / drop the
verdict. Now keeps keys in English with values in the target language,
extracts the outermost {...} with a regex (replacing a buggy lstrip that
could corrupt JSON), and falls back to the longest candidate when the
verdict is empty.

summarizer: document_summarizer crashed with AttributeError — it used the
old Chroma `_collection.get()` API against the Weaviate store. Added a
tenant-scoped fetch_all_for() helper to collections.py and switched the
tool to use it.
