feat: CloudNest.ai — full multi-tenant conversational AI platform

The full journey from day 1 to today. This commit captures the cumulative
state of the project across roughly two weeks of work: a Streamlit MVP
that grew into a branded, multi-tenant, three-provider platform with auth,
per-user RAG, agent tools, voice, vision, multilingual support, and a
landing page.

=== PHASE 1 — INITIAL BUILD ===

Bootstrapped the project from scratch as a single-user RAG + agent system:
- FastAPI backend with LangGraph ReAct agent loop
- Chroma vector store with BAAI/bge-small-en-v1.5 embeddings (384-dim)
- 9 production tools: document_search, document_summarizer, web_search,
  calculator, json_parser, datetime_tool,
  unit_converter, currency_converter, weather
- Streaming responses via SSE with live tool-trace timeline
- OCR pipeline for PDFs (pypdf + Llama-4 Scout 17B vision fallback)
- Attachment extraction route (text + vision for scanned content)
- Streamlit MVP as the first UI
- Started Next.js 15 migration

=== PHASE 2 — FRONTEND MIGRATION ===

Replaced Streamlit with a proper Next.js 15 + Tailwind frontend:
- Full UI parity with the Streamlit version, then much more
- SQLite-backed chat session persistence with LLM-generated titles
- Dark/light theme system via CSS variables (cyan accent dark, indigo light)
- Markdown + LaTeX rendering for assistant responses
- Multi-LLM ensemble feature: fan out to 3 Groq models in parallel, judge
  ranks them with JSON output, synthesized verdict
- Side-by-side ensemble UI with winner highlighting
- Voice in (faster-whisper STT) and voice out (Edge TTS) integration
- Fixed: hydration mismatches, CORS, file-extension routing, dropdown
  z-index clipping, cyan-in-light-mode polish

=== PHASE 3 — MULTILINGUAL + AUTH FOUNDATION  ===

Added 37-language support and started multi-tenancy:
- 37 languages with matched native TTS voices (en, ur, ar, hi, es, fr, de,
  ...) using Microsoft Edge neural voices
- Language directive injected into system prompt; tool outputs translate
  to fit the conversation naturally
- README rewrite (long, comprehensive, honest)
- Demo script for one-take screen recording
- Multi-tenancy Phase 1: Postgres 17 in Docker, SQLAlchemy 2.0 async,
  fastapi-users with JWT auth, Alembic migrations
- Bug-fixed: Postgres password volume staleness (manual volume rm), native
  PG17 port 5432 collision (disabled Windows service)
- Business clarification: this is for CEO-promotion portfolio, not a
  startup pitch — stack and copy aligned accordingly

=== PHASE 4 — MULTI-TENANCY COMPLETE  ===

Completed Phase 2 of multi-tenancy and started Phase 4a:
- Storage migration: SQLite chat history fully replaced by Postgres-backed
  sessions/messages models
- JWT auth required on every endpoint (rag, agent, sessions, voice, attach)
- Per-user RAG: each user gets their own Chroma collection named by user
  hex; user_id is read from a contextvar set at the agent entry point
- 8 production bug fixes: non-UUID session ids (uuid5 fallback), missing
  system user FK violation (manual INSERT), asyncpg orphaned connections
  (persistent bg loop pattern), cross-loop pool contamination (two
  SQLAlchemy engines), stale uvicorn auto-reload masking new routes
- Phase 4a started: httpOnly cookie auth backend (dual transport — Bearer
  JWT for API/curl + httpOnly cookie for browser, sharing one JWTStrategy)
- All 8 backend auth tests passed (Bearer regression, cookie login 204 +
  set-cookie, cookie persistence, cookie logout, no-cookie 401)

=== PHASE 5 — PHASE 4 COMPLETE + CLOUDNEST REBRAND ===

Completed Phase 4 frontend integration and rebranded to CloudNest.ai:
- Phase 4b: auth-gated app shell, credentials: include on every fetch,
  401-redirect in apiFetch(), UserButton in sidebar showing avatar +
  display_name + email + logout
- Phase 4c: DocumentManager UI — per-user upload/list/delete with size +
  chunk metadata, 10MB cap, drag-and-drop, defensive client-side validation
- Tool hardening: defensive numeric coercion in currency_converter and
  unit_converter (accept float | int | str, strip commas/underscores,
  parse to float) — fixes real Groq schema validation bug where the LLM
  passes "2100000" as a string
- OpenRouter provider integration: third LLM provider alongside Groq and
  Ollama. ChatOpenAI with custom base_url + HTTP-Referer/X-Title headers.
  Multi-LLM ensemble is now provider-aware — when LLM_PROVIDER=groq fans
  out across Groq models, when LLM_PROVIDER=openrouter fans out across
  OpenRouter models. Same OpenAI-protocol code works for both.
- ENSEMBLE_MODELS_OPENROUTER and ENSEMBLE_JUDGE_MODEL_OPENROUTER added
- CloudNest.ai brand: full landing page at /, chat app moved to /chat.
  Reusable Wordmark component (cloud-line icon + "CloudNest" cyan gradient
  + ".ai" subtle mono). Landing sections: TopNav, Hero with mocked chat
  screenshot, Features grid (6 cards), Provider switch demo with .env
  code mockup, How it works (3 steps), Tech stack (6 cards + "Under the
  hood" list), Final CTA, Footer with "Built by Munir" + LinkedIn +
  GitHub links
- Page metadata updated to "CloudNest.ai - Conversational AI platform
  you can actually run"
- Complete demo recording playbook: 7-scene shot list with timestamps,
  word-for-word voice-over script, demo CSV data, pre-flight checklist
- Hit Groq free-tier daily token limit (100k TPD) twice during testing

=== BUGS DEBUGGED ACROSS THIS PROJECT (cumulative) ===

1. Postgres password volume staleness (docker-compose down -v + volume rm)
2. Native PG17 port 5432 collision with Docker (disabled Windows service)
3. Missing fastapi_users_db_sqlalchemy import in Alembic migration
4. Non-UUID session ids fixed with uuid5 hash fallback in _coerce_uuid
5. Missing system user causing FK violation (manual INSERT)
6. asyncio.run() orphaning asyncpg connections (persistent bg loop pattern)
7. Cross-loop pool contamination (two SQLAlchemy engines: engine for main
   loop, bg_engine via get_or_create_bg_engine() for background tasks)
8. Stale uvicorn auto-reload masking new routes (hard restart required)
9. Groq strict schema validation rejecting LLM-quoted numeric tool args
   (defensive coercion + widened type signatures in calculator,
   currency_converter, unit_converter)
10. Frontend hydration mismatches (theme bootstrapping in layout.tsx)
11. CORS allow_credentials with explicit origins (not "*")
12. File-extension dispatch routing in attachment extraction
13. Dropdown z-index clipping in chat composer
14. Cyan-in-light-mode polish across all theme tokens
15. LLM filename hallucination in CSV flows (mitigated by disabling tools)
